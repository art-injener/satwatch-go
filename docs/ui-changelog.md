# История изменений UI

Документ фиксирует ключевые изменения пользовательского интерфейса Satellite Scout в формате semver.

## Формат записи

Для каждой версии указываются:
- дата релиза;
- список изменений по UI/UX;
- затронутые файлы;
- мотивация изменений.
