# История изменений UI

Документ фиксирует ключевые изменения пользовательского интерфейса Satellite Scout в формате semver.

## Формат записи

Для каждой версии указываются:
- дата релиза;
- список изменений по UI/UX;
- затронутые файлы;
- мотивация изменений.

## v0.1.4 — 2026-03-23

### Изменения
- Расписание сеансов наблюдения в правой панели: время AOS/LOS в **локальном** часовом поясе (раньше отображалось как UTC).
- SkyView: AOS/LOS и «Осталось» согласованы с таблицей — не подменяются временем последней точки `sky_path`; учёт **server skew** (`satellite_group_update.ts`), как в таблице.

### Затронутые файлы
- `static/js/right-panel.js`, `static/js/skyview.js`, `static/js/app.js`

### Мотивация
- UX-TIME-SYNC-001: устранить расхождение времён и оставшегося времени сеанса между таблицей и SkyView.
