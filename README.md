# 🛰️ Satellite Scout

Satellite Scout — это кроссплатформенное веб-приложение для отслеживания спутников (прежде всего CubeSat) в реальном времени.

ПО рассчитывает и отображает орбиты космических аппаратов на карте мира, проекции небесной сферы, а также выводит всю информацию по спутникам в специальной панели.
Для интеграции с поворотными устройствами есть графики индикации азимута и угла места наведения антенны.

В планах реализация приема телеметрии через RTL-SDR приемник и демодуляции ТМИ CubeSat.

## Предыстория

В одной из статей на Хабре про [ретро-компьютеры](https://habr.com/ru/articles/846270/) я наткнулся на скриншот DOS-программы **STSPLUS** (STSORBIT PLUS) — трекера спутников, написанного **David H. Ransom, Jr.**
Программа рассчитывала и рисовала орбиты космических аппаратов. Её использовали в NASA и даже в центре подготовки космонавтов в Звездном городке.

Я загорелся запустить STSPLUS на своём компьютере и посмотреть этот тёплый ламповый интерфейс вживую.

Мне пришлось перебрать несколько версий программы и несколько эмуляторов, разобраться с зависаниями при отрисовке карты и орбит.

Автор программы, к сожалению, [умер в 2006 году](https://celestrak.org/software/dransom/stsplus.html). Исходный код STSPLUS так и не был опубликован.

Я решил создать современную версию этой программы с расширенным функционалом.

## Что сейчас умеет Satellite Scout

- **Карта мира (Earth View)** — отрисовка наземной трассы орбиты, зоны видимости, обновление позиции спутника раз в секунду.
- **Небесная сфера (Sky View)** — отрисовка азимутальной проекции неба с траекторией пролёта.
- **Индикаторы положения антенны** — график азимута и угла места наведения антенны.
- **Панель информации** — информация о точке наблюдения и текущем отслеживаемом спутнике.
- **План сеансов** — расписание всех пролётов спутников на ближайшие сутки.
Выводится информация о времени появления (AOS), максимуме (TCA) и времени исчезновения (LOS), траектории.

## Технологии

| Слой | Технологии |
|------|-----------|
| **Backend** | Go 1.24+, REST API, SSE (Server-Sent Events), Go templates |
| **Frontend** | HTMX, Vanilla JS, Canvas 2D (карта, графики), CSS Grid |
| **Данные** | TLE с Celestrak, SGP4 пропагация, WGS84 |
| **Протокол** | SSE для real-time (позиции 1/сек, треки 30/сек) |

Вся математика выполняется на сервере (Go), фронтенд только рисует.

## Запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/satellite-scout.git
cd satellite-scout

# Сборка
make build

# Запуск
make run

# Открыть в браузере
# http://localhost:8080
```

При первом запуске приложение автоматически загрузит TLE-данные с Celestrak.
